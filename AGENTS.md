# Tally

Let your agent pay, only for what tallies.  An AI agent may pay only for an item a merchant signed, at the signed price, to the registered merchant, inside your rules. A Solana program checks every payment, and anything else reverts.

Package manager: pnpm.

## Commands

- build: `pnpm build`
- test: `pnpm test`
- build: `cargo build`
- test: `cargo test`

## Layout

- `app/`
- `crates/`
- `docs/`
- `mcp/`
- `programs/`
- `scripts/`
- `sdk/`
- `tests/`

## Rules

- Run `pnpm test` before you say a change is done.
- Never commit secrets or `.env` files.
